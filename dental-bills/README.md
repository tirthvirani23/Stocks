# Virani Dental Clinic – Bill Maker

A phone app (web page) that makes patient bills as PDF by voice.

**Use it:** tap the big button and say the patient name, treatment and amount, in English or Gujarati.
Examples: “Ramesh Patel, root canal, 3500, cash” · “રમેશ પટેલ, રૂટ કેનાલ, સાડા ત્રણ હજાર, રોકડા”.
Several treatments work too: “Kiran Shah scaling 800 and filling 1200 GPay”. “Tooth 36” is added to the treatment.
Check the boxes, tap **Make Bill (PDF)** and send it on WhatsApp or print it.

**History** tab: totals for today, this month and all time; bills grouped by date; search by name;
tap a bill to share it again or delete it; download all bills as a CSV file (opens in Excel); backup / restore.

Bills are stored only on the phone. Use **Backup all bills** once a month and save the file to iCloud Drive or WhatsApp.

## Put it on the iPhone
1. Turn on GitHub Pages: repository **Settings → Pages → Branch** = the branch with this folder, folder `/ (root)` → Save.
2. On the iPhone, open `https://tirthvirani23.github.io/Stocks/dental-bills/` in **Safari**.
3. Share button → **Add to Home Screen**.
4. First time you tap the mic, allow the microphone and speech recognition.
   If the mic does nothing: Settings → General → Keyboard → **Enable Dictation** on, and Settings → Siri on.
