# Echo Practice

Three pages that show one YouTube video at a time, with Previous / Next, a numbered list, done marks and speed control.

- `practice-1.html`: playlist 1
- `practice-2.html`: playlist 2
- `practice-3.html`: playlist 3 plus one extra video
- `index.html`: links to all three

The playlists are read live from YouTube, so new videos added to them show up automatically.

## Get a link (free, GitHub Pages)

1. On GitHub open this repository → **Settings** → **Pages**.
2. Under **Build and deployment**, Source: **Deploy from a branch**. Pick the branch that has this folder and the `/ (root)` folder. Save.
3. After a minute or two the pages are at `https://<your-username>.github.io/<repo-name>/echo-practice/`.

Opening the files straight from your computer may show a YouTube error, because YouTube wants the page to come from a website. Use the GitHub Pages link instead.
